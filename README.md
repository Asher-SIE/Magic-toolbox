# MagicToolbox

MagicToolbox 是一款专为 macOS VoiceOver 视障用户设计的辅助工具，提供实时翻译、剪贴板管理、文本处理等核心功能。

## 功能特性

### 翻译功能
- **实时翻译**：支持 VoiceOver 朗读内容的即时翻译
- **多语言支持**：涵盖 38+ 种语言，包括英语、中文、法语、日语、韩语、西班牙语等
- **离线翻译**：使用腾讯混元大模型（需下载模型文件），无需网络连接

### 剪贴板管理
- **历史记录**：自动保存剪贴板内容，支持浏览历史
- **多选操作**：支持勾选多条记录进行批量复制、删除
- **编辑功能**：内置文本编辑器，支持撤销/重做（⌘Z / ⌘⇧Z）
- **快捷处理**：去空白、合并空格、数字转中文、分句等功能

### 文本处理
- 移除空白字符（⌥+1）
- 合并多个空格为单个空格（⌥+2）
- 阿拉伯数字转中文（⌥+3）
- 标点符号转换行/分句（⌥+4）

### 语音增强
- **VoiceOver 集成**：专为 VoiceOver 设计，无缝配合屏幕阅读器使用
- **字符解释**：查看单个字符的详细解释
- **行列统计**：实时显示当前文本的行列位置

## 环境要求

- macOS 12.0+
- Python 3.10+
- Homebrew（用于安装依赖）

## 安装步骤

### 1. 克隆项目

```bash
git clone <repository-url>
cd Magic-toolbox
```

### 2. 创建虚拟环境

```bash
python3 -m venv venv
source venv/bin/activate
```

### 3. 安装依赖

```bash
pip install -r requirements.txt
```

### 4. 下载翻译模型

翻译功能需要下载腾讯混元大模型（GGUF 格式）：

1. 访问 Hugging Face 下载模型文件（如 `hunyuan-*.gguf`）
2. 将模型文件放置到任意目录
3. 首次运行时通过应用内的"设置"面板选择模型文件

### 5. 运行应用

```bash
python main_UI.py
```

## 使用说明

### 界面导航

应用采用左侧导航 + 右侧内容的面板布局：

- **翻译面板**：输入文本进行翻译
- **剪贴板面板**：浏览和管理剪贴板历史
- **设置面板**：配置翻译模型路径

### 快捷键列表

| 快捷键 | 功能 |
|--------|------|
| ⌥+1 | 移除空白字符 |
| ⌥+2 | 合并多个空格 |
| ⌥+3 | 数字转中文 |
| ⌥+4 | 标点转换行 |
| ⌥+C | 当前字符解释 |
| ⌥+D | 英译中（VO内容） |
| ⌥+⇧+D | 中译英（VO内容） |
| ⌥+T | 打开剪贴板编辑器 |
| ⌥+A | 追加VO内容到列表 |
| ⌥+⇧+7 | 剪贴板列表上一条 |
| ⌥+⇧+8 | 当前剪贴板上一行 |
| ⌥+⇧+9 | 剪贴板列表下一条 |
| ⌥+⇧+J | 设置剪贴板内容到系统 |
| ⌥+⇧+K | 当前剪贴板下一行 |
| ⌥+⇧+U | 当前剪贴板前一个字 |
| ⌥+⇧+I | 当前字符解释 |
| ⌥+⇧+O | 当前剪贴板后一个字 |
| ⌥+⇧+M | 剪贴板综述（行列信息） |
| ⌘+Z | 撤销（编辑器） |
| ⌘+⇧+Z | 重做（编辑器） |

### 文本编辑器

编辑剪贴板内容时，支持以下快捷操作：

- **⌘Z**：撤销
- **⌘⇧Z**：重做
- **⌥+1-4**：快速文本处理
- **Esc**：取消编辑

## 构建打包

### 使用打包脚本

```bash
chmod +x build.command
./build.command
```

打包完成后，应用将生成在 `dist/MagicToolbox.app`

### 注意事项

- 确保 `resources` 目录存在并包含必要的资源文件
- 首次打包需安装 PyInstaller：`pip install pyinstaller`

## 项目结构

```
Magic-toolbox/
├── main_UI.py          # 主界面代码
├── processer.py        # 核心处理器（翻译、剪贴板、VO）
├── setting.py          # 配置与国际化
├── resources/          # 资源文件
│   └── dict.txt        # 本地词典
├── locales/            # 国际化文件
│   ├── zh_CN/          # 中文翻译
│   └── en/             # 英文翻译
├── build.command       # 打包脚本
├── MagicToolbox.spec   # PyInstaller 配置
└── requirements.txt    # Python 依赖
```

## 技术栈

- **GUI**：wxPython 4.2
- **翻译模型**：llama.cpp + 腾讯混元
- **系统集成**：appscript、PyObjC
- **打包工具**：PyInstaller
